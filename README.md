# 🤖 AI-Assisted Resume Portfolio Generator

An AI-powered web application that transforms a user's resume into a professional portfolio website automatically.

The application accepts a `.txt` or `.docx` resume, processes the content using the Gemini API, structures the information into portfolio data, and dynamically generates a complete HTML portfolio.

👉 https://resume-portfolio-generator-ccv9.onrender.com/

## ✨ Features

- 📄 Upload resumes in `.TXT` or `.DOCX` format
- 🤖 AI-powered resume processing using Gemini API
- 🧹 Resume text cleaning and validation
- 🧠 Automatic extraction and structuring of resume information
- 🎨 Automatically generated portfolio website
- 👀 Portfolio preview before downloading
- ⬇️ Download generated `portfolio.html`
- 🖥️ Responsive and modern user interface
- 🔐 Gemini API key handled through environment variables
- ☁️ Deployed and accessible online through Render
